# Audio Plugin Visual Design Specification

## Core Visual Identity

The plugin UI should feel:

- Futuristic
- Neon-lit
- Dark-mode focused
- Premium and cinematic
- Inspired by stage lighting and modern music production tools

The visual style combines:

- Synthwave aesthetics
- Professional audio software
- Minimal modern UI
- Concert/stage lighting atmosphere

Avoid:

- Flat grayscale
- Bright white surfaces
- Heavy skeuomorphism
- Overly glossy textures
- Cartoonish glow effects

---

# Background & Surface System

The UI uses layered dark surfaces instead of pure black.

## Background Colors

| Purpose | Hex |
|---|---|
| Deep Background | `#0A0E14` |
| Surface 1 | `#11161D` |
| Surface 2 | `#181E29` |
| Surface 3 | `#202634` |
| Border / Divider | `#2A3342` |

Guidelines:

- Use subtle gradients instead of flat fills.
- Create depth through lighting and contrast.
- Borders should remain soft and minimal.
- The interface should resemble a dim recording studio or stage environment.

- Colors should softly glow.
- Bloom should remain controlled and atmospheric.
- Neon Green and Magenta should be used sparingly for emphasis.

# Glow Philosophy

Glow is a core part of the UI language.

Glow communicates:

- Focus
- Activity
- State
- Hierarchy
- Interaction

Glow should feel:

- Soft
- Diffused
- Atmospheric
- Premium

Avoid:

- Overexposed bloom
- Cheap neon effects
- Excessive blur

---

# Spotlight / Focus Lighting System

A defining feature of the design is warm stage-style spotlight lighting.

This lighting intentionally contrasts against the cool neon palette.

The spotlight should resemble:

- A single hanging bulb
- Concert stage lighting
- Warm cinematic focus light

Characteristics:

- Warm amber tone
- Slight haze/fog
- Soft edges
- Downward direction
- Subtle atmospheric fade

Purpose:

- Guide attention toward important controls
- Create emotional warmth
- Add depth and hierarchy
- Emphasize tactile controls

# Typography

Typography should be:

- Modern sans-serif
- Thin to medium weight
- Clean and geometric
- High contrast
- Slightly futuristic

Avoid:

- Serif fonts
- Playful rounded fonts
- Overly condensed text

# Gradient Direction

Preferred gradient flows:

- Blue → Cyan → Green
- Blue → Purple → Magenta
- Cyan → Blue → Purple
- Green → Blue → Purple

Gradients should:

- Feel luminous
- Blend smoothly
- Avoid harsh transitions

Recommended uses:

- Metering
- Waveforms
- Active states
- Decorative lighting
- Motion effects

---

# Motion & Animation

Animations should feel:

- Smooth
- Controlled
- Premium
- Ambient

Recommended behaviors:

- Soft pulsing glow
- Hover bloom
- Animated gradients
- Fading transitions
- Responsive metering

Avoid:

- Aggressive movement
- Fast flashy transitions
- Excessive bouncing

---

# Emotional Tone

The plugin should feel like:

- A futuristic synthesizer
- A premium DAW plugin
- A nightclub lighting rig
- A cinematic stage environment

The intended emotional response is:

- Immersive
- Energetic
- Atmospheric
- Stylish
- Professional

---

# Final Design Summary

The intended plugin aesthetic is a fusion of:

- Neon cyberpunk UI
- Professional audio software
- Stage lighting design
- Minimal modern interfaces
- Atmospheric cinematic lighting

The core visual identity comes from:

1. Dark layered surfaces
2. Vibrant neon accents
3. Soft glow behavior
4. Warm theatrical spotlight lighting
5. Minimal but high-contrast typography
6. Controlled visual hierarchy
7. Cinematic focus direction

The spotlight system is especially important because it introduces warmth and emotional direction into an otherwise cool futuristic palette.

This contrast is a defining feature of the design language.
